# EyeCare Android

Εφαρμογή Android για τοπικές υπενθυμίσεις φαρμάκων. Προσθέτεις τις ώρες
στο κινητό και καταχωρίζεις τις λήψεις στο ιστορικό. Ο προγραμματισμός και
το ιστορικό παραμένουν στη συσκευή.

## Εγκατάσταση και δοκιμή

1. Εγκατέστησε το APK σε Android 8.0 ή νεότερο και άνοιξε το EyeCare.
2. Ενεργοποίησε τις ειδοποιήσεις. Σε Android 12 ή νεότερο, ενεργοποίησε
   επίσης την άδεια ακριβούς ώρας από την αντίστοιχη ρύθμιση του EyeCare.
3. Πάτησε «Δοκιμή ειδοποίησης» και κλείδωσε την οθόνη. Με την άδεια
   ακριβούς ώρας, η ειδοποίηση προγραμματίζεται για 15 δευτερόλεπτα αργότερα.
4. Πάτησε «Προσθήκη φαρμάκου» και γράψε το όνομα. Μπορείς να επιλέξεις
   ισοκατανομή μεταξύ πρώτης και τελευταίας ώρας, σταθερό διάστημα εντός
   της ημέρας ή συγκεκριμένες ώρες. Ο έλεγχος ωρών δείχνει πότε θα
   ειδοποιεί το EyeCare. Η προαιρετική ημερομηνία λήξης συμπεριλαμβάνεται.

## Build

Χρειάζεσαι Java 17, Gradle 8.13 και Android SDK API 36.

```sh
gradle :app:assembleDebug :app:lintDebug
```

Το GitHub Actions ανεβάζει το δοκιμαστικό APK ως artifact του build. Τα
debug APK που υπογράφονται με διαφορετικά κλειδιά δεν εγκαθίστανται ως
αναβάθμιση της ίδιας εφαρμογής. Η απεγκατάσταση διαγράφει τις τοπικές
υπενθυμίσεις και το ιστορικό.
